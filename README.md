# Number Guessing Game

A CLI-based Number Guessing Game built in Java as part of the [roadmap.sh](https://roadmap.sh/projects/number-guessing-game) challenge.

## Features

- **Difficulty Levels:** Choose between Easy, Medium, and Hard.
- **Attempt Tracking:** Keeps count of your guesses.
- **Feedback System:** Provides hints ("Too high" or "Too low") to help you find the mystery number.

## Prerequisites

To run this game, you need to have the **Java Development Kit (JDK)** installed on your machine.

## How to Run

1. Clone the repository:
```
git clone https://github.com/JoaoVPatricio/number-guessing-game
cd number-guessing-game
```

2. Run the game with:
```
java Main.java
```

Alternatively, you can open the project in your preferred IDE and run the Main.java file directly.
